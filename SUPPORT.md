# Support

For help using a Dagitali project:

1. Review the repository README and documentation.
2. Search existing issues and discussions.
3. Use GitHub Discussions when the repository enables it.
4. If the behavior appears to be a defect, open a bug report using the repository's issue form.

Do not use public support channels to disclose security vulnerabilities. Follow [SECURITY.md]
instead.

- [What to Include](#what-to-include)

## What to Include

When asking for help, provide the affected project version or commit, relevant runtime and
operating-system versions, and the steps or exact command that led to the problem. Describe the
expected and observed results and whether the problem is reproducible. For automation failures,
identify whether the failure occurred locally or in CI and include relevant workflow/job details.

Include a minimal example and relevant diagnostics where possible. Inspect logs, screenshots,
configuration, and examples before sharing; omit credentials, personal information, private
repository content, and other confidential material. Follow the affected repository's instructions
for any additional details or private support channels.

Project-specific support instructions take precedence over this document.
