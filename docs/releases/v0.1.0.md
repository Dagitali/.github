# Dagitali GitHub Defaults v0.1.0

Version 0.1.0, tagged on 2026-09-29, adds community-health defaults and reusable GitHub Actions
workflows, composite actions, and starters. This retrospective record was prepared on 2026-10-04
from local Git history. The annotated `v0.1.0` tag resolves to commit
`343330b0b87f9533b59d5c07542097bdf5defcaa`, the merge of `release/0.1.0`. The tag's recorded date is
not a verified publication date.

## Highlights

- Adds bug, feature, and documentation forms, the issue chooser, and the PR template.
- Adds contribution, conduct, security, support, and organization-profile documentation.
- Introduces reusable Python CI, Python package, Python publish, AWS CDK CI, Swift CI, and
  dependency-review workflows under `.github/workflows/`.
- Adds `setup-python-project`, `python-quality`, and `cdk-quality` composite actions under
  `actions/`, plus Python/CDK/Swift starters with matching properties files.
- Adds editor/Git conventions, ignore patterns, pre-commit configuration, and Actions guidance.

## Change Scope

The [initial scaffold] had no executable shared automation. This version establishes the initial
interfaces; the later hardening recorded in [v0.2.0] is not part of this tag.

## Compatibility and Configuration

Consumers explicitly reference shared workflows/actions and retain small caller workflow files.
Starters are copied into consumers, not automatically executed across all repositories. Community
defaults remain distinct from explicitly called automation.

The tagged Python CI defaults to Python 3.12/3.13 and configurable quality commands. CDK CI accepts
Python or Node projects and includes synthesis. Swift CI targets Swift packages with a default
`macos-15` runner. These are declared defaults, not proof of hosted-tested support.

The tagged `python-publish.yml` declares artifact download, a protected-environment input, and OIDC
permissions for a trusted-publishing attempt. Its presence does not prove that the reusable
publishing design worked or published a package. Version [v0.2.0] removes that path in favor of
consumer-owned release automation; that later design is not part of this tag.

## Support Boundary

This is a community-default and automation library, not a Python distribution, AWS deployment
project, or Xcode application. Consumers supply project layouts, dependencies, commands, and hosted
configuration. Installation, build, and synthesis commands execute project code.
