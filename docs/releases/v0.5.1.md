## Change Scope

The complete branch updates `.github/RELEASE-NOTES-TEMPLATE.md`, `CHANGELOG.md`, the archive index,
and the eight existing version records from v0.0.0 through v0.5.0. Preparation adds this record.

The template generalizes scope-dependent guidance, retains automation compatibility, artifact,
consumer adoption, and rollback requirements, and separates artifact contracts from validation
results. Historical records link concise highlights to their dated changelog entries, retain
detailed scope, move v0.2.0 breaking boundaries into Compatibility and Configuration, and link
outstanding checks from release-specific follow-up actions rather than duplicating checklists.

The archive adopts navigation-first ordering, explicit document responsibilities, centralized
Evidence Boundaries and Release Operations, and descriptive destination-sorted reference links.
Existing anchors, recorded timezones, historical scope, and preparation outcomes are preserved.
Preparation acknowledges the existing local v0.5.0 tag without attributing later documentation
changes or new test results to its immutable tree.

No workflows, composite actions, starters, tests, dependencies, Make targets, audit configuration,
community defaults, or consumer files change. No hosted settings are remediated.
